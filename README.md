# Portfolio 2026 - Proyecto Web

Para arrancar con este trabajo, lo primero que hice fue ponerme a bocetar en Figma para darle forma a la idea que tenía en la cabeza. Al principio me costó un montón, sobre todo con el tema de los componentes y el comportamiento del scroll, porque no lograba que quedara como yo quería. Estuve un buen rato con eso y por momentos sentía que no le encontraba la vuelta.
De hecho, arranqué armando páginas, pero mientras iba avanzando me di cuenta de que no me convencía el resultado y que podía resolverlo mucho mejor. Así que decidí, reestructurar todo y armar otra propuesta con la que me sentí muchísimo más cómoda y conforme.
Después pasé al código en Visual Studio Code con HTML5 y CSS. Fui armando toda la estructura usando las etiquetas que correspondían, ordenando las secciones y sumando las imágenes y los contenidos multimedia. Con CSS me encargué de pulir el diseño, acomodar los elementos, definir la paleta de colores, las tipografías y lograr que todo tuviera una identidad visual armónica.
