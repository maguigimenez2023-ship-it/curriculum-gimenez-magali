# Curriculum Vitae - Proyecto Web

Hice un trabajo práctico para crear un currículum vitae usando Visual Code. 
Usé HTML para armar la estructura, CSS para darle diseño y Flexbox para organizar
los elementos de forma ordenada y que se vea bien en diferentes pantallas.
Quedó un currículum simple, claro y fácil de leer.

## Descripción del trabajo:

Este proyecto consiste en el desarrollo
en formato web, utilizando HTML y CSS y FLEXBOX.

## Tamaño de pantalla:

1920 × 1080 píxeles

## Editor de código que se utilizo fue:

Visual Studio Code
